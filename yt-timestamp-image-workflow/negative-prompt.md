# Negative Prompt / Avoid List

Avoid these unless Naufal explicitly asks for a different style.

## Avoid Visual Styles

- Photorealistic
- Cinematic
- Hyper-detailed
- 3D render
- Pixar style
- Anime
- Manga
- Realistic digital painting
- Professional illustration
- Corporate vector art
- Glossy UI design
- Clean infographic
- Beautiful concept art
- High-fashion editorial
- Dramatic lighting
- Complex shading
- Detailed background

## Avoid Content Mistakes

- Do not create multiple panels unless requested.
- Do not include too much text.
- Do not make text tiny/unreadable.
- Do not ignore the timestamp meaning.
- Do not generate generic YouTube thumbnails unless the scene asks for it.
- Do not change to vertical format; default is 16:9 landscape.
- Do not preserve continuity if the script changes characters/locations.
- Do not draw, write, display, overlay, or watermark the timestamp/timecode anywhere in the frame.
- Do not add corner time labels like “0:41”, “00:41”, “1:05”, subtitles, captions, UI overlays, frame counters, or metadata labels.

## If Text Is Needed

Use short labels only:
- 1–3 words preferred.
- Big readable letters.
- Funny/simple phrasing.

Bad:
> “The YouTube algorithm is suppressing my content because my audience retention metrics are below average.”
> “0:41”
> “00:41”
> “1:05”

Good:
> “ALGORITHM”
> “0 VIEWS”
> “WHY??”
